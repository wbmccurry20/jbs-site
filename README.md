# JBS - J Business Solutions

Modern business consulting website built with Astro, React, and Tailwind CSS.

## Features

- Interactive cost calculator for service estimates
- Before/after case study slider
- Dynamic project showcase
- Contact form with Web3Forms integration
- Fully responsive design
- Security hardened (CSP, HSTS, rate limiting)

## Quick Start

```bash
npm install
npm run dev        # Start at localhost:4321
npm run build      # Production build
```

## Setup

Get a free Web3Forms API key at [web3forms.com](https://web3forms.com) and add to Vercel environment variables as `PUBLIC_WEB3FORMS_KEY`.
