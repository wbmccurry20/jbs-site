## Image Guidelines

- **Format**: JPG for photos, PNG for logos/graphics, SVG for icons
- **Optimization**: Compress all images (use ImageOptim, TinyPNG, or Squoosh)
- **Size**: 
  - Hero images: 1920x1080px
  - Project thumbnails: 800x600px minimum
  - Before/After: Same dimensions for both images
- **Quality**: High resolution, professional photography
- **Lighting**: Well-lit, shows detail
- **Consistency**: Similar style across all photos

## Where to Get Images

1. **Professional Photography** (recommended)
   - Hire local photographer for projects
   - Drone shots for aerial views
   - Before/after documentation

2. **Temporary Placeholders**
   - Unsplash (free, high quality)
   - Pexels (construction-themed)
   - Can use until professional photos ready

3. **Stock Images** (if needed)
   - Shutterstock
   - Adobe Stock
   - Only for general construction scenes
